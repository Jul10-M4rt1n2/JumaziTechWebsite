# 🚀 Início Rápido - GitHub Pages

## Para Publicar o Site Agora:

### Passo 1: Ativar GitHub Pages
1. Acesse: https://github.com/Jul10-M4rt1n2/JumaziTechWebsite/settings/pages
2. Em **"Source"**, selecione **"GitHub Actions"**
3. Clique em **"Save"** (se necessário)

### Passo 2: Executar o Deployment
Opção A - Automático (recomendado):
- Faça merge desta Pull Request para a branch `main` ou `master`
- O deploy acontecerá automaticamente

Opção B - Manual:
1. Vá para: https://github.com/Jul10-M4rt1n2/JumaziTechWebsite/actions
2. Clique em **"Deploy to GitHub Pages"**
3. Clique em **"Run workflow"**
4. Selecione a branch e clique em **"Run workflow"**

### Passo 3: Aguardar
- O processo leva 2-3 minutos
- Acompanhe o progresso na aba Actions

### Passo 4: Acessar o Site
Após o deploy, seu site estará em:
```
https://jul10-m4rt1n2.github.io/JumaziTechWebsite/
```

## 🔧 Solução de Problemas

**Site não carrega?**
- Aguarde alguns minutos após o primeiro deploy
- Verifique se o workflow foi executado com sucesso
- Limpe o cache do navegador (Ctrl + Shift + R)

**Alterações não aparecem?**
- Confirme que fez commit e push
- Verifique se o workflow foi executado na branch correta
- Aguarde o deploy completar (veja na aba Actions)
